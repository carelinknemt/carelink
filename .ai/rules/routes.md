# Routes

## Regenerate wayfinder with --with-form
Generated by `@laravel/vite-plugin-wayfinder` with `formVariants: true`. If you regenerate manually, you MUST run `php artisan wayfinder:generate --with-form`, otherwise the `.form()` helpers disappear and starter-kit auth pages (login/register/etc.) fail `tsc --noEmit`.
