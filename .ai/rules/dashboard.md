# Dashboard

## Keep form controls in the same row equal-height
Never put helper/hint text under a single control inside a multi-column grid cell: it makes that column taller and the neighbor input/dropdown look misaligned with dead space beneath. Put the hint below the whole grid, and keep every control in a shared row the same size (no sm selects next to lg buttons; stack them instead).
